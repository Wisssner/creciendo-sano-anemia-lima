Cómo funciona en tres pasos

1Se completan los datos disponiblesPeso, talla, fecha de nacimiento, el establecimiento de referencia y el control de hemoglobina anterior, si lo hay.
2El sistema compara con miles de atenciones anterioresBusca niñas y niños con un perfil parecido y observa cuántos de ellos presentaron anemia.
3Devuelve una prioridad, no un diagnósticoSirve para decidir a quién conviene llevar primero a un control de hemoglobina, y ayuda a preparar el mensaje para la familia.

El sistema no diagnostica ni indica tratamientos. El rol del docente es informar y acompañar a la familia; la anemia se confirma únicamente con la prueba de hemoglobina realizada por personal de salud.
